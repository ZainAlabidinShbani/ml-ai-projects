# Bayesian Medical Risk Analyzer

Professional overview and UI walkthrough for a desktop Bayesian risk analysis tool.

## Project Overview

Bayesian Medical Risk Analyzer is a Windows desktop application that uses Bayesian inference to estimate patient risk based on clinical features. The application provides a full workflow from data import and training to analytics and live inference.
